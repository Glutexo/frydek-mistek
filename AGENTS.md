# Pravidla pro tento repozitář

Tento soubor slouží jako lokální pracovní pravidla pro projekt turistického průvodce po Frýdku-Místku.

## Jazyk a styl

- Všechny nové texty piš česky.
- Všechny nové texty piš s českou diakritikou.
- Pokud upravuješ existující text, převeď jej při té příležitosti do češtiny s diakritikou.
- Piš stručně, věcně a přehledně.

## Pracovní postup

- Tento repozitář slouží jako základ pro turistického průvodce po Frýdku-Místku.
- Poznámky ukládej průběžně do přehledně členěných markdown souborů.
- Po každé změně proveď commit a push.

## Obsah projektu

- Soustřeď se na podklady pro turistického průvodce po Frýdku-Místku.
- Udržuj odděleně poznámky k místům, dopravě, historii a dalším tématům.
- Podkladové soubory, jako jsou mapy nebo obrázky, ukládej do složky `assets/`.
